# Facial Expression Recognition using ResNet50

This project detects human emotions from facial expressions in real-time using a webcam.  
The model is trained using the **FER2013 dataset** and implemented using **TensorFlow, OpenCV, and ResNet50**.

## Features
- Real-time face detection using OpenCV
- Emotion classification using a trained deep learning model
- Displays emotion labels on webcam feed

Supported emotions:
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

---

## Dataset
The model was trained using the **FER2013 facial expression dataset**, which contains grayscale images of faces labeled with seven emotions. :contentReference[oaicite:1]{index=1}
